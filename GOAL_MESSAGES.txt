================================================================================
NeuroGolf 2026 — driver /goal messages
================================================================================

HOW TO USE
  1. Open Claude Code in the root of this repository.
  2. Pick a lane below and paste its /goal message as your first prompt.
  3. Fill in the TWO placeholders — everything else resolves inside this repo:
       <YOUR CHATGPT PROJECT URL>  a ChatGPT project you own
       <YOUR BROWSER ID>           the Claude for Chrome browser to drive
  4. Put HF_TOKEN=... in .env at the repo root first (see README, Setup).

FINDING YOUR BROWSER ID
  Connect Claude for Chrome, then ask Claude Code to run list_connected_browsers.
  It prints a deviceId per browser (e.g. a1b2c3d4) — use the one whose logged-in
  ChatGPT account owns the project above, and paste its id into the goal message.
  Match on deviceId, NOT on the display name: the names are positional and shift
  between sessions. One lane per browser at a time; to run two lanes at once, use
  a second browser and a second ChatGPT project.

PREREQUISITES (once, before any lane)
  - skills-offline.zip must exist and be uploaded into that ChatGPT project's
    Sources. Build it with the daily-bundle lane below; upload is manual.
  - The tasklist for the lane must list the tasks you want driven, one per line:
      zzz_sessions/neurogolf_<lane>_tasklist.txt
  - Claude for Chrome must be connected, and the browser you name must be logged
    into the ChatGPT account that owns the project.

NOTES
  - Correctness gate for every lane is the examples shipped in
    skills-offline/evaluate/scripts/neurogolf-2026/task{NNN}.json. Pass 100% of
    them and the candidate ships. Nothing else is required.
  - Sessions think for a long time (often 30-90 min). A session still working is
    not a blocker: skip it this pass and come back.
  - Each lane writes only into its own artifact folders, manifests and mapping,
    so two lanes can run side by side in different ChatGPT projects.

================================================================================
